# Curated publication results

These CSV files are the lightweight numerical outputs underlying the principal tables and claims in the manuscript. Large MAT files containing trained networks, complete workspaces, and intermediate checkpoints were intentionally excluded from the public package because the code and final synthetic datasets are sufficient to regenerate them.

`staged_inverse_comparison.csv` combines the final Stage-1, Stage-2, and Stage-3 comparison tables retained in the original archive.
